Diagnostic Medical Center

Περιγραφη

Η εφαρμογη ειναι ενα προγραμμα κονσολας σε Java για τη διαχειριση ενος διαγνωστικου κεντρου. Υποστηριζει γιατρους, ασθενεις, εξετασεις, ραντεβου και βασικα στατιστικα εσοδων.

Αρχεια κωδικα

- Main.java: βασικο μενου και χειρισμος επιλογων χρηστη.
- MedicalCenter.java: λιστες δεδομενων και βασικοι ελεγχοι εγκυροτητας.
- Doctor.java, Patient.java, Appointment.java: βασικες οντοτητες.
- Exam.java και οι subclasses ImagingExamination, MicrobiologicalExamination, SpecializedExamination: τυποι εξετασεων και υπολογισμος κοστους.
- DataStore.java και CsvMedicalCenterStore.java: φορτωση και αποθηκευση δεδομενων.
- InputHelper.java: ελεγχος εισοδου απο την κονσολα.

Αρχεια δεδομενων

Η εφαρμογη διαβαζει και γραφει τα παρακατω αρχεια στον ιδιο φακελο:

- doctors.txt
- patients.txt
- exams.txt
- appointments.txt

Αν δεν υπαρχει κανενα απο τα παραπανω αρχεια, δημιουργουνται αρχικα δεδομενα. Αν υπαρχουν μονο μερικα απο αυτα, η εφαρμογη σταματα για να μην δουλεψει με ελλιπες dataset.
